Сервис «Покрытие»

Учебный сервис беспилотного автомобиля. Теперь страницы и данные отдает приложение на FastAPI, а не сервер на сокетах из занятия Т4.Б1.1.

Калькулятор тормозного пути

Форма отправляет запрос методом GET к программному интерфейсу /api/braking. Ответ придет в формате JSON.

Условия торможения

Примеры адресов

  • /api/braking?v=60&mu=0.7 – тормозной путь на сухом асфальте
  • /api/braking?v=-10&mu=0.7 – отрицательная скорость, код 422
  • /api/surfaces – список покрытий в формате JSON
  • /index.html – старый адрес, код 301 и перенаправление
  • /nowhere – несуществующий адрес, код 404
  • /docs – автоматическая документация программного интерфейса
