## Веб-приложение на FastAPI: маршруты, модели Pydantic, автоматическая документация

Второе занятие Темы 4 «Разработка веб-приложений» курса «Искусственный интеллект» для 9 класса. Ученики переносят сервер сервиса «Покрытие» из занятия Т4.Б1.1 с сокетов на фреймворк FastAPI и видят, какую работу фреймворк берет на себя: разбор запроса, сборку ответа, ответы 404 и 405, отдачу файлов, проверку данных. Входные и выходные данные описываются моделями Pydantic, а документацию программного интерфейса на странице `/docs` FastAPI строит сам. Задания проверяются автоматическими тестами `pytest` с тестовым клиентом FastAPI. Занятие продолжает практическую работу №1 по программе.

## Теория (презентация и ноутбук)

1. **Фреймворк вместо нас.** Какие функции сервера из Т4.Б1.1 больше не нужны и кто делает их работу. Устройство FastAPI: сервер Uvicorn по стандарту ASGI, библиотеки Starlette и Pydantic. Первое приложение, запуск командой `fastapi dev main.py` на адресе `http://127.0.0.1:8000`, автоматический перезапуск. Сравнение с Flask.
2. **Маршруты и параметры.** Декораторы `@app.get` и `@app.post`, страницы HTML, перенаправление, файлы `StaticFiles`. Параметры пути и параметры запроса с подсказками типов, ограничения `Query(gt=0, le=200)` и `Path(ge=1)`. Ответ 422: поля `loc`, `type`, `msg`; функция при ошибке не вызывается.
3. **Модели Pydantic и документация.** Модель `TripIn` с полями `Field(...)` и перечислением `Surface`. Тело запроса в формате JSON и код 201. Модель ответа `response_model` и почему служебные поля не уходят клиенту; ответ 404 через `HTTPException`. Автоматическая документация: `/docs`, `/redoc`, `/openapi.json`, описания, теги, пример тела запроса. Обработчики `def` и `async def` и почему в курсе используется `def`.
4. **Практика.** План из шести заданий и проверка командой `pytest`.

## Практическая работа

| Задание | Что пишем | Главный результат |
| --- | --- | --- |
| З1 | `basics.py`: подсказки типов, `count_calls`, `register` | повторение: подсказки типов трех функций, декоратор со счетчиком вызовов, декоратор с параметром, устроенный как `@app.get` |
| З2 | страницы и файлы | `/` и `/surfaces` из Т4.Б1.1, перенаправление 301, папка `static`, первый ответ JSON `/api/surfaces`; 404 и 405 FastAPI отправляет сам |
| З3 | `GET /api/braking` | `?v=60&mu=0.7` – тормозной путь 36,9 м; отрицательная скорость и нулевой коэффициент – ответ 422 |
| З4 | `Surface`, `TripIn`, `POST /api/trips` | поездка в формате JSON сохраняется с кодом 201; ошибка в поле – 422 с именем поля |
| З5 | `TripOut`, `GET /api/trips/{trip_id}` | служебное поле `client_host` не попадает в ответ; нет поездки – 404 |
| З6 | описания для документации | у каждого маршрута краткое описание и тег, у полей и параметров описания, пример тела запроса в `/openapi.json` |

Задания повышенной сложности: опыт с медленными обработчиками `def`, `async def` с `time.sleep` и `async def` с `await asyncio.sleep` при пяти одновременных запросах; промежуточный обработчик (middleware), который пишет в журнал метод, путь, код и время ответа.

## Как работать

```
cd ПР_FastAPI/server
python -m pip install -r requirements.txt
pytest                      # проверить все задания
pytest tests/test_z3.py     # проверить одно задание
pytest -m extra             # задания повышенной сложности
fastapi dev main.py         # запустить приложение: http://127.0.0.1:8000/ и http://127.0.0.1:8000/docs
```

Если команда `fastapi` не найдена, работает `python -m fastapi dev main.py`.

## Требования

Python 3.12 или новее, библиотеки из `requirements.txt` (FastAPI 0.162.0 со стандартным набором, pytest, requests) через школьное зеркало PyPI, браузер Chrome или Edge, редактор VS Code. Порт 8000 должен быть свободен.

Страница `/docs` загружает свои скрипты из сети доставки контента cdn.jsdelivr.net. Если в школьной сети этот адрес закрыт, преподаватель один раз скачивает три файла, перечисленные в `server/static/docs/README.md`, и кладет их в папку `server/static/docs`: документация заработает без интернета.
